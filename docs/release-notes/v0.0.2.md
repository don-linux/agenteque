agenteque 0.0.2 is the workspace. The window is now the editor: a file tree, markdown tabs, a terminal and themes, with settings for how it looks and how the terminal reads. It is still an alpha, and this release is the interface. Opening a folder loads a built-in demo rather than a folder on disk, the terminal echoes what you type, and the browser bar does not load pages.

**Download agenteque:** [Mac (Apple Silicon)](https://github.com/don-linux/agenteque/releases/download/v0.0.2/agenteque-v0.0.2-macos-arm64.dmg) · [Windows (portable)](https://github.com/don-linux/agenteque/releases/download/v0.0.2/agenteque-v0.0.2-x86_64-windows-portable.exe) · Linux: [AppImage](https://github.com/don-linux/agenteque/releases/download/v0.0.2/agenteque-v0.0.2-x86_64.AppImage), [.deb](https://github.com/don-linux/agenteque/releases/download/v0.0.2/agenteque-v0.0.2-x86_64.deb), [.rpm](https://github.com/don-linux/agenteque/releases/download/v0.0.2/agenteque-v0.0.2-x86_64.rpm), [.tar.gz](https://github.com/don-linux/agenteque/releases/download/v0.0.2/agenteque-v0.0.2-x86_64-linux.tar.gz)

SHA-256 checksums are in `checksums.txt`.

The Linux packages need glibc 2.25 or newer, which every currently supported release of Ubuntu, Debian and Fedora has.

- **AppImage**, to try it without installing: `chmod +x agenteque-v0.0.2-x86_64.AppImage`, then run it.
- **Debian and Ubuntu:** `sudo apt install ./agenteque-v0.0.2-x86_64.deb`
- **Fedora:** `sudo dnf install ./agenteque-v0.0.2-x86_64.rpm` (openSUSE Tumbleweed: `sudo zypper install` with the same file)

On Windows, `agenteque-v0.0.2-x86_64-windows-portable.exe` runs without installing. It is not signed yet, so SmartScreen may warn the first time: click **More info**, then **Run anyway**.

The Mac app is not signed by Apple yet. The first time, open it from Finder, then go to **System Settings → Privacy & Security** and click **Open Anyway**. From a terminal, `xattr -dr com.apple.quarantine /Applications/agenteque.app` does the same.

## Added

- **The workspace.** A file tree, a markdown editor with tabs, and a terminal you can dock at the bottom or on the right, or open on its own. By @don-linux. (#7)
- **Themes and terminal settings.** Fifteen interface themes and fifteen terminal themes, plus the terminal font and size. The choice is saved in a JSON file and is still there the next time the app starts. By @don-linux. (#7)
- **Settings.** Three pages: Terminal, Themes, and Browser. The Browser page shows the app, Electron, Chromium and Node versions this build is running. By @don-linux. (#7)
- **A home screen.** Recent folders, and an Open folder button that opens the demo workspace. By @don-linux. (#7)
- **The browser bar.** Back, forward, the address field and the rest of the toolbar. It is the interface only: nothing loads in the page area yet. By @don-linux. (#7)
- **Shortcuts for macOS, Windows and Linux.** Command on macOS, Control on Windows and Linux, including the chords for the terminal, the file tree and the browser bar. By @don-linux. (#7)
- **An application icon**, in the window, the taskbar and the installer. By @don-linux. (#7)

## Changed

- **A larger window.** It opens at 1280×800, so the tree, the editor and the terminal fit. By @don-linux. (#7)
