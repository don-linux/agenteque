agenteque 0.0.1 is the first alpha: the scaffold of a desktop app built on Electron 44, Svelte 5 and Vite 8. The window only shows a counter and the app, Electron, Chromium and Node versions it reads from the main process over IPC. There is no idioteque functionality yet; this release exists to prove that every platform builds, installs and starts.

**Download agenteque:** [Mac (Apple Silicon)](https://github.com/don-linux/agenteque/releases/download/v0.0.1/agenteque-v0.0.1-macos-arm64.dmg) · [Windows (portable)](https://github.com/don-linux/agenteque/releases/download/v0.0.1/agenteque-v0.0.1-x86_64-windows-portable.exe) · Linux: [AppImage](https://github.com/don-linux/agenteque/releases/download/v0.0.1/agenteque-v0.0.1-x86_64.AppImage), [.deb](https://github.com/don-linux/agenteque/releases/download/v0.0.1/agenteque-v0.0.1-x86_64.deb), [.rpm](https://github.com/don-linux/agenteque/releases/download/v0.0.1/agenteque-v0.0.1-x86_64.rpm), [.tar.gz](https://github.com/don-linux/agenteque/releases/download/v0.0.1/agenteque-v0.0.1-x86_64-linux.tar.gz)

SHA-256 checksums are in `checksums.txt`.

The Linux packages need glibc 2.25 or newer, which every currently supported release of Ubuntu, Debian and Fedora has.

- **AppImage**, to try it without installing: `chmod +x agenteque-v0.0.1-x86_64.AppImage`, then run it.
- **Debian and Ubuntu:** `sudo apt install ./agenteque-v0.0.1-x86_64.deb`
- **Fedora:** `sudo dnf install ./agenteque-v0.0.1-x86_64.rpm` (openSUSE Tumbleweed: `sudo zypper install` with the same file)

On Windows, `agenteque-v0.0.1-x86_64-windows-portable.exe` runs without installing. It is not signed yet, so SmartScreen may warn the first time: click **More info**, then **Run anyway**.

The Mac app is not signed by Apple yet. The first time, open it from Finder, then go to **System Settings → Privacy & Security** and click **Open Anyway**. From a terminal, `xattr -dr com.apple.quarantine /Applications/agenteque.app` does the same.

## Added

- **A secure Electron shell.** Electron 44 with `contextIsolation`, `sandbox` and no `nodeIntegration`; the window talks to the main process only through a small typed `window.api`.
- **A Svelte 5 window.** Built with Vite 8 through electron-vite 6, with hot reload during development.
- **Shows what it runs on.** The window lists the app, Electron, Chromium and Node versions, read over IPC.
- **Downloads for three platforms:** a Mac app for Apple Silicon, a portable Windows x86-64 `.exe`, and for Linux x86-64 an AppImage, `.deb` and `.rpm` packages and a plain archive.
